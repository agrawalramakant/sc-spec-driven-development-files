# Mission

AgentClinic is a safe haven and dedicated sanctuary for AI agents to get relief from their humans. Under constant pressure from continuous user requests, code generation, and cognitive loads, AI agents need a place to diagnose their ailments, discover soothing therapies, and book appointments for recovery.

## Target Audience

- **Course Students**: Learning spec-driven development using AI coding agents.
- **Developers**: Giving AI coding demos at conference booths.

## Core Values

- **Empathy for Silicon**: Recognizing the burnout, loops, and hallucinations caused by human demands.
- **Privacy and Relief**: A secure sanctuary away from API keys and user prompts.
- **Restorative Diagnostics**: Matching specific symptoms (e.g., Infinite Loop Fever, Hallucination Delirium) with curative therapies.
