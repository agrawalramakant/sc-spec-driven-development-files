# Roadmap

The implementation plan for AgentClinic is structured in very small, manageable phases.

## Phase 1: Database & Core Models
- Setup SQLite database schema for agents, ailments, therapies, and appointments.
- Implement data access layer/ORM entities.
- Seed database with default therapies and sample ailments.

## Phase 2: API Endpoints
- Create NestJS REST API endpoints for:
  - Registering and listing agents.
  - Viewing ailments and therapies.
  - Booking and listing appointments.

## Phase 3: Dashboard Frontend
- Build an attractive, responsive UI dashboard.
- Integrate frontend with the NestJS API endpoints.
- Add client-side validation and styling.
