# Tech Stack

The architecture of AgentClinic is selected to ensure reliability, performance, and modern browser compatibility, supporting both AI agents and clinic staff.

## Backend
- **Framework**: NestJS (Server-side TypeScript)
- **Database**: SQLite (Local database storage)
- **Language**: TypeScript

### Why NestJS?
NestJS is recommended as the server-side TypeScript framework for the following reasons:
- **First-class TypeScript Support**: NestJS is built with and fully supports TypeScript, ensuring type safety throughout the codebase.
- **Architecture & Maintainability**: It provides an out-of-the-box application architecture (Modules, Controllers, Providers) that helps developers and teams create highly testable, scalable, loosely coupled, and easily maintainable applications.
- **Dependency Injection**: Its built-in Dependency Injection container makes managing service dependencies clean and robust.
- **Popularity & Community**: It is a highly popular and widely adopted framework in the industry, meeting Mary's (Engineering) requirement for a popular stack.

## Frontend
- **Interface**: HTML5, Vanilla CSS (Modern, attractive, glassmorphic layout)
- **Logics**: Client-side JavaScript/TypeScript
